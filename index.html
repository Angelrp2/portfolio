TFG

♪ Musify

Musify

Plataforma web de creación musical. El usuario describe una idea, elige género y ánimo y la aplicación genera la letra de una canción. Permite reproducirla con voz sintetizada, buscar artistas en MusicBrainz y gestionar playlists y favoritos.

  • API REST en PHP 8.2 con autenticación JWT (HMAC-SHA256) y contraseñas bcrypt
  • Base de datos SQLite de 6 tablas e integración con la API de MusicBrainz
  • Despliegue con Docker y Apache
  • PHP
  • JavaScript
  • SQLite
  • JWT
  • Docker
